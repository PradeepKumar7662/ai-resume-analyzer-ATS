# 🤖 AI Resume Analyzer

An AI-powered Resume Analyzer that helps users analyze their resumes and get useful feedback based on their selected job role.

The application allows users to upload their resume, analyze it using AI, and receive structured feedback to improve their resume.

## 📌 About The Project

AI Resume Analyzer is a web application designed to help job seekers understand how well their resume matches a particular job role.

Users can upload their resume, select a job, and analyze their resume to receive AI-generated feedback, including resume scoring, strengths, weaknesses, and improvement suggestions.

The project focuses on providing a simple, modern, and user-friendly resume analysis experience.
